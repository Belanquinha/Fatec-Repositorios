+# ARCHITECTURE — Fatec-Repositorios (Back-End)
+
+> Contexto para agentes e desenvolvedores. Documenta a arquitetura ativa,
+> o que funciona, o que está em planejamento e o que evitar.
+
+## Visão geral
+
+Aplicação Spring Boot 4.1 (Java 21), API REST, com autenticação via Azure AD (MSAL),
+banco PostgreSQL, contador de uploads gerenciados por arquivo.
+
+## Pilares da arquitetura
+
+| Camada | Responsabilidade | Notas |
+|---|---|---|
+| **Controller** | Receber requisição, validar, delegar | Sem lógica de negócio |
+| **Service** | Regras de negócio, orquestração | Um método só executa uma operação |
+| **Repository** | Persistência JPA | Query methods, não QueryDSL |
+| **Security** | Autenticação/MSAL, JWT, filtros | Todo acesso autenticado |
+| **Config** | Configuração Spring, OpenAPI, MVC | Centralizado |
+| **Seed** | Dados iniciais (CSV, JSON) | Carregados via `data.sql` |
+
+## Fluxos principais
+
+### Login (MSAL)
+1. Front-end redireciona para Azure AD (tenant `eabe64c5-68f5-4a76-8301-9577a679e449`).
+2. Azure AD retorna código de autorização → backend troca por token (MSAL).
+3. Backend extrai UPN (e-mail) → `CustomUserDetailsService` carrega/usa `User`.
+4. `JwtTokenProvider` assina token HS256 com `JWT_SECRET` do `.env`.
+5. `JwtAuthenticationFilter` injeta `SecurityContext` em cada request.
+6. `SecurityConfig` → todos os `POST /projetos` exigem `hasRole(ALUNO)` (ver bug registrada).
+
+### Postagem de projeto
+1. Aluno envia `ProjetoCreateRequest` (e-mail do professor responsável, instituição, integrantes).
+2. `ProjetoService.criar()` salva com estado `AGUARDANDO_APROVACAO`.
+3. `ProjetoRepository.save()` → trigger/DAO insere `data.sql`.
+4. Resposta `ProjetoResponse` com `id`, `titulo`, `estado`.
+
+### Upload de arquivo (capa, avatar, etc.)
+1. `UploadController` recibe multipart → `FileStorageService`.
+2. `FileStorageService.store()` salva em `/app/uploads` (volume Docker).
+3. Retorna `UploadResponse` com URL para o front.
+4. **NOVO**: verificar erros de upload antes de concluir (ver `README.md` no root).
+
+## Modelos essenciais
+
+| Entidade | Estados principais |
+|---|---|
+| `Projeto` | `AGUARDANDO_APROVACAO`, `APROVADO`, `REJEITADO`, `EM_REMOCAO`, `REMOVIDO` |
+| `User` | `ALUNO`, `PROFESSOR`, `ADMIN` (roles) |
+| `Instituicao` | Catálogo de instituições Fatec/CPS |
+| `Integrante` | Participantes de um projeto |
+| `ProfessorInstituicao` | Vinculação professor ↔ instituição |
+
+## Banco
+
+- PostgreSQL 17 (Docker, porta `5433` local)
+- Schema: `schema.sql` (cria tabelas)
+- Seeds: `data.sql` + `back-end/init/` (SQL + geração de instituições)
+- `application.yml` — datasource, jpa, flyway/seeder, multipart uploads
+
+## Configuração de ambiente
+
+`.env` na raiz (nunca versionar). Variáveis essenciais:
+
+```bash
+POSTGRES_PASSWORD=<gerado>
+JWT_SECRET=<32+ chars>
+JWT_ISSUER=fatec-repository-api
+JWT_EXPIRATION_HOURS=24
+MSAL_TENANT_ID=eabe64c5-68f5-4a76-8301-9577a679e449
+MSAL_CLIENT_ID=146c36f9-abf3-48b0-a533-5f462e5e4eed
+```
+
+## O que está funcionando (confirmados)
+
+- ✅ Login MSAL via Azure AD (rotor, roles baseados em domínio)
+- ✅ Classificação de papel por domínio de e-mail (centralizada no backend)
+- ✅ Seleção 0–4 instituições pelo professor (catálogo)

+

+- 🔜 Exclusão/anonimização de projetos (LGPD Art.18)
+
+## Regras para agentes
+
+- Nunca alterar `JWT_SECRET` para um valor pré-definido.

+/**
+ * Envio de e-mails assíncrono/não crítico do back-end.
+ *
+ * <p>Envia para o professor responsável logo após a submissão de um projeto.
+ * A mensagem é "melhor-esforço": se o SMTP falhar, o erro é logado e a
+ * submissão do aluno <b>nunca</b> é bloqueada. Isso evita que um problema
+ * pontual de e-mail impeça o registro do projeto.</p>
+ *
+ * <p>Envio feito no back-end (não no front-end): o naveador não envia e-mail
+ * para destinatários arbitrários por segurança (CORS + exposição de
+ * credenciais), e o professor já está gravado no modelo {@link Projeto} via
+ * {@code emailProfessorResponsavel}, então não precisamos de mais um cadastro.</p>
+ */
+@Service
+@Slf4j
+public class EmailService {
+
+    private final JavaMailSender javaMailSender;
+
+    public EmailService(JavaMailSender javaMailSender) {
+        this.javaMailSender = javaMailSender;
+    }
+
+    /**
+     * Notifica o professor responsável logo após o aluno submeter o projeto.
+     *
+     * @param projeto   projeto recém-criado (já persistido em {@code salvo}).
+     * @param autor     autor (aluno) do projeto.
+     */
+    public void enviarNovoProjeto(Projeto projeto, User autor) {
+        String professorEmail = projeto.getEmailProfessorResponsavel();
+        if (professorEmail == null || professorEmail.isBlank()) {
+            log.warn("Projeto {} sem e-mail do professor responsável; pulando notificação", projeto.getId());
+            return;
+        }
+
+        // Prefere um endereço "oficial" do projeto; se não foi declarado, usa
+        // a conta SMTP ativa (o nome de exibição vira o endereço).
+        String from = System.getenv("EMAIL_FROM");
+        if (from == null || from.isBlank()) {
+            from = System.getenv("MAIL_USERNAME");
+        }
+        if (from == null || from.isBlank()) {
+            from = professorEmail; // fallback para não gerar mensagem de "de" inválido
+        }
+
+        try {
+            MimeMessage message = javaMailSender.createMimeMessage();
+            MimeMessageHelper helper = new MimeMessageHelper(message, false, "UTF-8");
+            helper.setFrom(from);
+            helper.setTo(professorEmail);
+            helper.setSubject("[Fatec Repositório] Novo projeto submetido para avaliação");
+            helper.setText(buildHtmlBody(projeto, autor), true); // true = HTML
+            javaMailSender.send(message);
+            log.info("E-mail de notificação enviado para {} sobre o projeto {}", professorEmail, projeto.getId());
+        } catch (Exception e) {
+            log.error("Falha ao enviar e-mail de notificação para o professor {} sobre o projeto {} — a submissão continuou normalmente",
+                    professorEmail, projeto.getId(), e);
+        }
+    }
+
+    private String buildHtmlBody(Projeto projeto, User autor) {
+        StringBuilder sb = new StringBuilder();
+        sb.append("<!DOCTYPE html><html><body style=\"font-family: 'Segoe UI', Arial, sans-serif; color:#1f2937; background:#f3f4f6; margin:0; padding:24px;\">")
+                .append("<table role=\"presentation\" width=\"100%\" cellpadding=\"0\" cellspacing=\"0\" style=\"max-width:600px; margin:0 auto; background:#ffffff; border-radius:10px; overflow:hidden; box-shadow:0 1px 4px rgba(0,0,0,.12);\">")
+                .append("<tr style=\"background:#1d4ed8; color:#ffffff;\"><td style=\"padding:18px 22px; font-size:18px; font-weight:600;\">📦 Fatec Repositório</td></tr>")
+                .append("<tr><td style=\"padding:22px;\">")
+                .append("<h2 style=\"margin:0 0 8px; color:#111827;\">Novo projeto submetido</h2>")
+                .append("<p><b>Título:</b> ").append(escapeHtml(projeto.getTitulo())).append("</p>")
+                .append("<p><b>Descrição:</b> ").append(escapeHtml(projeto.getDescricaoCurta())).append("</p>")
+                .append("<p><b>Autor:</b> ").append(escapeHtml(autor.getNome())).append(" (")
+                .append(escapeHtml(autor.getEmail())).append(")</p>")
+                .append("<p><b>Instituição:</b> ")
+                .append(projeto.getInstituicao() != null ? escapeHtml(projeto.getInstituicao().getNome()) : "—")
+                .append("</p>")
+                .append("<p><b>Palavras-chave:</b> ")
+                .append(projeto.getPalavrasChave() == null || projeto.getPalavrasChave().isEmpty()
+                        ? "—"
+                        : String.join(", ", projeto.getPalavrasChave()))
+                .append("</p>")
+                .append("<p><b>Link do repositório:</b> ")
+                .append(projeto.getLinkRepositorio() == null || projeto.getLinkRepositorio().isBlank()
+                        ? "—"
+                        : "<a href=\"").append(escapeHtml(projeto.getLinkRepositorio())).append("\" style=\"color:#2563eb; text-decoration:underline;\">link</a>")
+                .append("</p>")
+                .append("<p><b>Estado:</b> <span style=\"color:#b91c1c;\">").append(projeto.getEstado() != null ? projeto.getEstado().name() : "—").append("</span></p>")
+                .append("<p style=\"color:#6b7280; font-size:12px; margin-top:18px; border-top:1px solid #e5e7eb; padding-top:12px;\">"
+                        + "Enviado automaticamente pelo Fatec Repositório &middot; "
+                        + "Este e-mail foi gerado após a submissão do projeto.")
+                .append("</td></tr>")
+                .append("</table>")
+                .append("</body></html>");
+        return sb.toString();
+    }

+        if (value == null) {
+            return "";
+        }
+        return value.replace("&", "&amp;")
+                .replace("<", "&lt;")
+                .replace(">", "&gt;")
+                .replace("\"", "&quot;");

+# PATTERNS — Fatec-Repositorios (Front-End)
+
+> Contexto para agentes e desenvolvedores. Documenta a paleta, os padrões
+> visuais e o que **evitar** ao trabalhar no front-end.
+
+## Paleta de cores (CSS variables)
+
+Definida em `front-end/src/styles/paleta.css` (root + `.dark`).
+
+| Role | Variável | Exemplo |
+|---|---|---|
+| **Vermelho CPS** | `--vermelho-500` | `#B20000` |
+| **Azul repositório** | `--azul-500` | `#4345CB` |
+| **Amarelo primário** | `--amarelo-500` | `#DCA703` |
+| **Verde sucesso** | `--verde-500` | `#00B32A` |
+| **Branco** | `--branco-500` | `#F4F6F9` |
+| **Cinza** | `--cinza-500` | `#202124` |
+
+### Uso correto
+
+- **Amarelo** → destaque, CTA, breadcrumb, badges de papel do usuário.
+- **Vermelho** → erros, rejeições, alertas, *_removido/_rejeitado*.
+- **Azul** → links, aviso de navegação, destaque de repositório.
+- **Verde** → sucesso, aprovação, estado _ativo_.
+- **Cinza** → texto secundário, fundos de sobreposto, skeletons.
+
+### Modo escuro
+
+`paleta.css` mapeia variáveis semânticas. Exceções são listadas em
+`front-end/src/styles/tema-escuro.css` (texto escuro sobre amarelo, fundos fixos,
+cores chapadas, links azuis). **Nunca** usar cores hardcoded em componentes.
+
+## Layout e componentes
+
+- **Mobile-first**: breakpoint `--mobile-brakepoint: 768px` (paleta.css).
+- **Angular 21** (standalone), TypeScript ~5.9, Tailwind CSS 4.
+- **Editor.js** para rich text em projetos pendentes/aprovados.
+- **Azure MSAL Angular** (`@azure/msal-angular`, v5) para login.
+- **Nginx** serve o build estático (Docker `front-end`).
+
+## O que evitar
+
+- ❌ Cores com hex (ex: `#B20000`) em componentes — usar variáveis semânticas.
+- ❌ Criar novas classes de cor sem consultar `paleta.css`.
+- ❌ Usar `v-if`/`hidden` para rotas protegidas — usar `auth.guard.ts`.
+- ❌ Carregar imagens via `http://` — usar `https://` ou `/uploads`.
+- ❌ Alteração de `theme-escuro.css` sem rodar `npm run build` e testar.
+- ❌ Duplicar estilos de palette no CSS — extrar para variáveis.
+
+## Componentes essenciais (matíz)
+
+| Componente | Responsabilidade | Caminho |

+| `header/header` | Navegação, logo, auth | `src/app/shared/components/header` |

+import { Component, OnInit, inject, signal } from '@angular/core';
+import { CommonModule } from '@angular/common';
+import { Router } from '@angular/router';
+import { ThemeService } from '../../core/theme/theme.service';
+import { AuthService } from '../../core/auth/auth.service';
+
+@Component({
+  selector: 'app-configuracoes',
+  standalone: true,
+  imports: [CommonModule],
+  templateUrl: './configuracoes.html',
+  styleUrl: './configuracoes.css'
+})
+export class Configuracoes implements OnInit {
+  private router = inject(Router);
+  private themeService = inject(ThemeService);
+  private authService = inject(AuthService);
+
+  modoEscuro = this.themeService.modoEscuro;
+  usuario = signal<{ nome: string; email: string; role?: string } | null>(null);
+  carregando = signal(true);
+
+  ngOnInit(): void {
+    this.authService.obterUsuarioLogado().then((u) => {
+      this.usuario.set(u);
+      this.carregando.set(false);
+    }).catch(() => this.carregando.set(false));
+  }
+
+  alternarTema(): void {
+    this.themeService.alternar();
+  }
+
+  sairDaConta(): void {
+    this.authService.logout().catch((erro) => {
+      console.error('Erro ao encerrar a sessão: ', erro);
+    });
+    this.router.navigate(['/']);
+  }
+}
