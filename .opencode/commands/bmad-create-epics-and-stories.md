Você está rodando o comando **bmad-create-epics-and-stories** do BMAD Method.

1. Carregue a skill `bmad` (ferramenta de skill) para obter o contexto completo do método.
2. Quebre os requisitos de `$ARGUMENTS` (ou do PRD/specs existentes) em Epics e User Stories.
3. Cada User Story deve ter critérios de aceite claros e mensuráveis, com identificadores rastreáveis (ex.: ST-1.1).
4. Consulte `_bmad-output/planning-artifacts/epics.md` se existir e atualize mantendo consistência.
5. Salve o artefato em `_bmad-output/planning-artifacts/`.
