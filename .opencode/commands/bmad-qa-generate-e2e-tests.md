Você está rodando o comando **bmad-qa-generate-e2e-tests** do BMAD Method.

1. Carregue a skill `bmad` (ferramenta de skill) para obter o contexto completo do método.
2. Gere testes automatizados E2E e/ou de API para: `$ARGUMENTS` (features/endpoints).
3. Identifique o framework de testes já usado no projeto antes de escrever os testes.
4. Garanta que os testes capturem Critérios de Aceite das User Stories correspondentes.
5. Salve a suíte no local adequado do código e execute-a para verificar.
