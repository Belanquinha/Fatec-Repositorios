Você está rodando o comando **bmad-prd** do BMAD Method.

1. Carregue a skill `bmad` (ferramenta de skill) para obter o contexto completo do método.
2. Crie, atualize ou valide o PRD (`_bmad-output/planning-artifacts/prd.md`) com base em: `$ARGUMENTS`.
